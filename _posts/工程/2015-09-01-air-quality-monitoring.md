> 河海大学 · 2015 · 个人小项目

## 背景

2015 年深度学习兴起带动了对大数据的需求，叠加当年环境污染等热点问题，导师定了一个方向就是把网上全国各个地方的实时空气质量 PM2.5 数据收集下来，这样后面可以用这个数据训练一个异常预警的模型系统。内部逻辑就是空气质量的变好与变坏肯定是跟异常的人为活动有关。

## 技术思路

<img src="/images/readme/hotmap1.png" style="zoom:25%;" />

基于 Java 语言调用空气质量发布网提供的 API，周期性获取 JSON 格式的全国各城市空气质量数据，包括：城市名称、经纬度坐标、时间和 PM2.5 数值。采集到的数据自动上传到 PostgreSQL 数据库，调用百度地图 API 以热力图形式展示各城市的空气质量变化与污染程度。

## 复盘

前后花了一个半月左右，借此了解了简单的软件开发、PostgreSQL 数据库应用、基于百度地图 API 的地理信息展示。对当时的我来说算是一个小小的成就达成，点燃了技术热情。
